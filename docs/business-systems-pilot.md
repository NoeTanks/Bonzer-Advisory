# Business systems pilot

This proposal adds `business-systems.html`; the homepage, domain configuration and existing service pages are unchanged. The page remains noindex during review.

## Included

- Separate Sutherland Shire and Richmond Hill positioning, indicative AUD/CAD package prices, and optional advisory services.
- Fictional quote follow-up, onboarding checklist and contribution calculator examples; these are concept demonstrations, not live vendor integrations.
- Existing Calendly discovery call URL with region/campaign parameters.
- Links to existing privacy and terms pages. No form backend, advertising pixel, software provisioning or payment collection.

## Before launch

1. Choose the initial supplier after written confirmation of branding entitlement, regional messaging support, account minimums, usage fees and cancellation/export terms. No software purchase is required to review this page.
2. Confirm package scope, taxes, usage allowances, support boundaries and final local prices. AUD/CAD figures are separate price tests, not conversions.
3. Obtain initial customer commitments before activating a fixed-fee reseller account. Client-owned software is an alternative for the first implementation.
4. Complete business email setup and test Calendly availability, confirmations and region-appropriate time zones.
5. Review customer terms/privacy for software delivery and any tracking added later.
6. Perform visual checks at mobile/desktop sizes and test all booking links before merging or promoting.
7. Replace pilot banners and remove noindex only when the offering is ready; select whether to link from the homepage or replace it in a separate reviewed change.

## Validation

The preview source passed JavaScript syntax and static ID/anchor checks. DOM-stub interaction checks covered quote sequencing/reset, demo selection, checklist state, contribution calculations, currency switching and Calendly tagging. These do not replace visual or real-browser acceptance testing.
